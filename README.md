# Book Management System

A React-based Book Management System with full CRUD functionality using MockAPI.

## Features

- View all books
- Add new books
- Edit existing books
- Delete books
- Search by title or author
- Filter books by genre
- Responsive UI

## Tech Stack

- React.js
- Vite
- Tailwind CSS
- Axios
- MockAPI

## Installation

```bash
npm install
npm run dev
```
